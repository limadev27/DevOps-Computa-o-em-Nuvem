Rollback instantâneo

Uma versão anterior está sempre pronta para assumir, com um único comando.

Do commit ao container, em quatro passos.

  1. 01

    Commit

    O código chega ao repositório e dispara o pipeline automaticamente.

  2. 02

    Build

    A imagem é construída em camadas com cache distribuído entre os workers.

  3. 03

    Deploy

    O Nimbus Core escolhe os nós ideais e realiza o rollout de forma gradual.

  4. 04

    Escala

    O tráfego real ajusta réplicas e recursos, sem intervenção manual.
